# Моя читалка

Русскоязычная Android-читалка PDF и TXT с локальной библиотекой и сохранением прогресса.

## Что уже заложено
- Импорт PDF/TXT через системный выбор файлов.
- Копирование книг во внутреннее хранилище приложения.
- Библиотека с поиском и блоком продолжения чтения.
- ZIP-резервная копия всей библиотеки: PDF/TXT, категории, прогресс, закладки, заметки, карточки повторения и оформление.
- Восстановление из резервной копии с проверкой архива и явным подтверждением замены текущей библиотеки.
- Экран статистики: прогресс библиотеки, завершённые и начатые книги, избранное, закладки, заметки, карточки к повторению, категории и недавние открытия.
- PDF: постраничный рендеринг по мере прокрутки, переход к странице.
- TXT: размер шрифта и переключение светлого/сепия фона.
- Сохранение библиотеки и прогресса локально через Preferences DataStore.
- Сборка APK через GitHub Actions.
- Отдельный сайт загрузки в каталоге `site/`.

## Сборка
Откройте проект в Android Studio (JDK 17, Android SDK 35) или запустите workflow **Android APK** на GitHub. Готовый debug APK будет доступен в Artifacts.

## Сайт
Каталог `site/` публикуется через GitHub Pages workflow. Сайт ведёт на страницу последних релизов GitHub. Пока релизный APK не опубликован, скачивание будет доступно после первой публикации релиза.

## Статус проверки
Исходники и CI-конфигурация добавлены. Сборка и запуск на устройстве считаются проверенными только после успешного выполнения GitHub Actions / реального теста на Android.
